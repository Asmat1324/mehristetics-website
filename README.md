# Mehristetic’s Website

Elegant, responsive German-language landing page built with plain HTML, CSS, and JavaScript. No build step required.

## Run locally
Open `index.html` in a browser or use a local static server.

## Deploy on Vercel
Framework preset: **Other**. Root directory: `./`. Build command: **leave empty**. Output directory: **leave empty** (Vercel serves the static files).

## Before launch
- Replace the CSS-generated abstract hero artwork with your approved brand photography if desired.
- Insert the approved logo asset and final brand font when supplied.
- Add verified booking/contact details; the contact section intentionally does not advertise an unverified address, phone number, social handle, or functional booking form.
- Review exact service names and descriptions before publishing.
- Add an Impressum and Datenschutzerklärung with accurate operator details before a German commercial launch.

The page intentionally avoids medical claims and unverified credentials.
